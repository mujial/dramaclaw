# Noor — Khuda AI Assistant ✨

Apka apna AI assistant — dua, Quran ki ayat, hadith, namaz-roza ki maloomat, tasbih counter aur voice chat ke saath.

## Features
- 💬 AI Chat (Hinglish / Urdu / English) — dua, ayat, hadith, namaz, roza, zakat, hajj, motivation
- 🎤 Voice input + voice reply (Text-to-Speech)
- 📿 Tasbih / Dhikr counter (33 / 99 / 100 goal)
- 🌙 Aaj Ki Roshni — roz ek nayi ayat/hadith
- 📴 Offline chalta hai (PWA)
- 📲 Phone me install hota hai — bilkul APK jaisa

## Phone me install kaise karein (2 minute)
1. `index.html` ko Chrome browser me kholo (ya is folder ko kisi hosting par upload karo)
2. Chrome menu (⋮) dabao → **"Add to Home screen"** ya **"Install app"**
3. Home screen par Noor ka icon ban jayega — tap karo, app khul jayegi! 🎉

## APK banana ho to (optional, free)
Agar asli `.apk` file chahiye:
1. Is folder ki saari files ko https://www.pwabuilder.com par upload karo → wahan se Android APK download ho jayega (free, no signup)
2. Ya files ko **WebIntoApp** / **AppsGeyser** me daal kar APK banao

## Files
- `index.html` — poora app (ek hi file me sab kuch)
- `manifest.json` — install ke liye
- `sw.js` — offline support
- `icon.png` — app logo
